# FEMNET

FEMNET is a numerical modelling tool dedicated to the mechanical assessment of flexible structures such as fishing gear and fish cages.

The modelling is based on the **finite element method**, with a specific emphasis on netting structures. FEMNET also takes into account cables, bars, floats and netting.

FEMNET runs on **Linux**.

## Main workflow

A FEMNET calculation follows the general sequence:

```text
./gengis ──────► *.don       description of the structure and its environment written by the user
  │
   ▼
./phobos ──────► *.mdg       description of the structure and its environment compatible with FEM
  │
   ▼
./unix ──────► *.sta       quasi-static equilibrium
  │
   ▼
./dyna ──────► *.dyn       dynamic calculation
  │
   ▼
./batz                    visualization of results
```

The main FEMNET tools are:

| Tool | Main function |
|---|---|
| `gengis` | Graphical tool helping to create a first level of a `*.don` file |
| `phobos` | Creates a `*.mdg` file compatible with the finite-element calculation |
| `unix` | Calculates the quasi-static equilibrium and records the result in `*.sta` |
| `dyna` | Calculates the dynamic equilibrium and records the result in `*.dyn` |
| `batz` | Displays the calculated equilibrium and results |

The main file types are:

- `*.don` — description of the structure and its environment
- `*.mdg` — finite-element model generated by `phobos`
- `*.sta` — quasi-static calculation results generated by `unix`
- `*.dyn` — dynamic calculation results generated by `dyna`

## Download

The FEMNET source code is available on GitHub:

**https://github.com/dpriour/femnet**

The original manual also mentions previous versions hosted on FEMNETting and IFREMER.

### Quick download

From the GitHub repository, choose:

**Code → Download ZIP**

Then place the required FEMNET directories in a directory such as:

```text
~/femnet
```

The manual describes two installation approaches:

1. Downloading the already prepared `programs` and `data_2001` directories.
2. Compiling FEMNET from source, including the `libsx` graphics library.

For the second approach, the manual describes compiling the components with `make` and placing the resulting executables in:

```text
~/femnet/programs
```

## First test

After installation, open a terminal and try:

```bash
cd ~/femnet/programs
./batz
./phobos
./gengis
```

If the corresponding graphical windows open, the basic installation is working.

## From design to equilibrium

The design of a structure defines its netting panels, cables and rigging.

This design is described in the `*.don` file. `phobos` reads this file and creates the `*.mdg` model used for the finite-element calculation.

The initial structure is not necessarily in equilibrium.

For a quasi-static calculation:

```text
*.don + *.mdg
      │
      ▼
    ./unix
      │
      ▼
    *.sta
```

The resulting equilibrium can then be displayed with `batz`.

For a dynamic calculation:

```text
*.don + *.mdg + *.sta
          │
          ▼
        ./dyna
          │
          ▼
        *.dyn
```

The dynamic results can also be visualized with `batz`.

## The `*.don` file

The `*.don` file is the main input file written by the user. It describes the structure and its environment.

It has two main parts:

1. A first part following a strict template.
2. A second part containing commands that do not need to follow a specific order.

The `*.don` file uses colons (`:`) as separators between comments and parameter values. When modifying an existing file, care should therefore be taken not to remove or add colons unintentionally.

The manual provides a detailed description of:

- netting panels;
- panel geometry and mesh coordinates;
- cables and bars;
- links between components;
- meshing order;
- node types;
- mechanical properties;
- hydrodynamic properties;
- environmental conditions;
- bottom-sea conditions;
- catch description;
- calculation convergence;
- numerical and dynamic parameters;
- requested calculation outputs.

## `gengis`

`gengis` is a graphical tool designed to facilitate the creation of a first-level `*.don` file.

Launch it with:

```bash
cd ~/femnet/programs
./gengis
```

The generated file is not necessarily complete and normally requires manual completion.

Typical operations include:

- choosing the plane of the design;
- drawing netting panels;
- defining mesh coordinates;
- creating cables;
- aligning nodes;
- defining node and cable types;
- creating links between components;
- adjusting the graphical scale;
- saving the first-level `*.don` file.

## `tool_box.ods`

The manual also describes `tool_box.ods`, a LibreOffice Calc spreadsheet used to help determine characteristics used in `*.don` files.

Among other things, it can be used to estimate values related to:

- twine and cable diameter;
- traction stiffness;
- volumic mass;

## `phobos`

`phobos` is used to transform the `*.don` description into the finite-element model `*.mdg`.

It also provides graphical visualization of the structure and allows inspection of panels, cables, nodes and other model characteristics.

## `unix`

`unix` calculates the quasi-static equilibrium of the structure.

It uses the `*.don` and `*.mdg` files and records the result in a `*.sta` file.

The manual discusses convergence, numerical parameters and refinement of the calculation.

## `dyna`

`dyna` performs dynamic calculations.

It uses:

- `*.don`
- `*.mdg`
- `*.sta`

and records the dynamic results in a `*.dyn` file.

The manual includes several dynamic examples, including:

- FAD;
- mussels longline;
- netting boom;
- fish cage;
- bottom seine.

## `batz`

`batz` is the graphical tool used to visualize quasi-static and dynamic results.

It uses mainly:

- `*.sta` for quasi-static results;
- `*.dyn` for dynamic results, when available.
